# 1️⃣ Network Types

## 🌍 1.1 The World of Networking

Networking is the process of connecting devices so they can
**communicate and exchange information**.

The Internet has become an essential part of everyday life. We use
connected networks to:

-   💬 Communicate with friends and family
-   🛒 Shop online
-   📸 Share pictures, videos, and experiences
-   🎓 Attend online courses
-   🎮 Play multiplayer games
-   📧 Send and receive emails
-   📹 Participate in video conferences
-   📰 Receive news and information

### 💡 Key Idea

> **Networking acts like a common language that allows different devices
> and people around the world to communicate.**

Networking uses **protocols**, which are rules that define how devices
communicate.

------------------------------------------------------------------------

## 🌐 1.2 What Is the Internet?

The **Internet** is a worldwide collection of interconnected networks.

It is often described as a:

> **"Network of networks."**

The Internet is not simply one physical network. It consists of many
smaller networks connected together and communicating through common
standards and protocols.

### 🔗 Internet Communication

Information can travel through different types of connections,
including:

-   ☎️ Telephone wires
-   🔌 Copper cables
-   💡 Fiber-optic cables
-   📶 Wireless transmissions
-   🛰️ Satellite links

These connections allow users to exchange many types of information,
such as:

-   Text
-   Images
-   Audio
-   Video
-   Files
-   Application data

------------------------------------------------------------------------

## 🏢 1.3 Who Owns the Internet?

### ❌ The Internet is not owned by one person or organization.

Instead, it is made up of **many interconnected networks** operated by
different organizations, companies, governments, institutions, and
individuals.

These networks cooperate using **common networking standards and
protocols**.

### ⭐ Remember

**Internet = Interconnected Networks + Common Standards +
Communication**

# 2️⃣ Data Transmission

## 📊 2.1 What Is Data?

**Data** is information that is created, entered, collected, stored, or
transmitted.

Whenever you:

-   📤 Send a message
-   📸 Upload a picture
-   🎥 Share a video
-   📧 Send an email
-   📁 Upload a file
-   📝 Enter information into a website

you are creating or transmitting data.

------------------------------------------------------------------------

# 🔐 2.2 Types of Personal Data

Personal data can be classified into three important categories.

## 1. 🙋 Volunteered Data

**Volunteered data** is information that a person **intentionally
provides or shares**.

### Examples

-   Social media profile information
-   Pictures
-   Videos
-   Text
-   Audio files
-   Information entered into online forms

### 💡 Easy Way to Remember

> **Volunteered = You intentionally give it.**

------------------------------------------------------------------------

## 2. 👀 Observed Data

**Observed data** is information collected by **recording or monitoring
a person's actions or activities**.

### Examples

-   📍 Location information collected by a mobile phone
-   📱 Device activity
-   🌐 Network activity
-   🚶 Movement or usage patterns

### 💡 Easy Way to Remember

> **Observed = Someone/something records your activity.**

------------------------------------------------------------------------

## 3. 🧠 Inferred Data

**Inferred data** is information that is **derived or analyzed from
other data**.

### Example

A credit card company may analyze your purchases to determine:

-   📍 Possible locations
-   🛍️ Shopping preferences
-   🍔 Eating preferences
-   📊 Spending patterns

A **credit score** is another example of information derived from
analysis of available data.

### 💡 Easy Way to Remember

> **Inferred = Information calculated or concluded from other data.**

------------------------------------------------------------------------

## 📝 Personal Data Comparison

  -----------------------------------------------------------------------
  Type                    Meaning                 Example
  ----------------------- ----------------------- -----------------------
  🙋 Volunteered          You intentionally       Social media profile
                          provide data            

  👀 Observed             Your activity is        Mobile location
                          recorded                

  🧠 Inferred             Data is derived through Credit score
                          analysis                
  -----------------------------------------------------------------------

### 🔑 Memory Trick

**V → O → I**

-   **V = Volunteered** → You give it
-   **O = Observed** → Your activity is recorded
-   **I = Inferred** → Information is calculated from data

# 🔢 2.3 The Bit

A **bit** is the smallest unit of digital data.

The word **bit** comes from:

> **Binary Digit**

A bit can have only **two possible values**:

-   `0`
-   `1`

### 💡 Example

A light switch can have two states:

-   OFF → `0`
-   ON → `1`

Computers use binary values to represent and process digital
information.

------------------------------------------------------------------------

# 💾 2.4 How Computers Represent Data

Computers process data using **binary**.

Human beings understand:

-   Letters
-   Numbers
-   Images
-   Audio
-   Video
-   Symbols

Computers represent all of these using patterns of **0s and 1s**.

### Input Process

**Human Interaction → Input Device → Binary Data → CPU**

### Output Process

**Binary Data → Output Device → Human-Readable Information**

### Examples

-   ⌨️ Keyboard converts keystrokes into binary data
-   🎤 Microphone converts sound into digital data
-   🖨️ Printer converts digital data into printed information
-   🔊 Speakers convert digital audio data into sound
-   🖥️ Monitor converts digital data into visual output

------------------------------------------------------------------------

# 🔤 2.5 ASCII

**ASCII** stands for:

> **American Standard Code for Information Interchange**

ASCII is a character encoding system used to represent characters
digitally.

In the course example, each character is represented using **8 bits**.

### Examples

``` text
A = 01000001
9 = 00111001
# = 00100011
```

------------------------------------------------------------------------

# 💽 2.6 Byte

A group of **8 bits** is called a:

> **Byte**

### Relationship

``` text
1 Byte = 8 Bits
```

### Example

``` text
01000001
```

This contains **8 bits = 1 byte**.

### ⭐ Important

-   **Bit** → `b`
-   **Byte** → `B`

Do not confuse:

-   `Mb` = Megabits
-   `MB` = Megabytes

------------------------------------------------------------------------

# 📡 2.7 Common Methods of Data Transmission

After data is converted into bits, those bits must be represented as
**signals** and transmitted through network media.

### 🌐 Network Media

Network media is the physical or wireless path through which signals
travel.

Examples:

-   🟤 Copper wire
-   💡 Fiber-optic cable
-   📶 Wireless electromagnetic waves

There are **three common methods of signal transmission**.

------------------------------------------------------------------------

## ⚡ 1. Electrical Signals

Data is represented as **electrical pulses** and transmitted through
copper cables.

### Used With

-   Copper Ethernet cables
-   Other copper-based network connections

### Signal

> ⚡ Pulses of electricity

------------------------------------------------------------------------

## 💡 2. Optical Signals

Data is converted into **light pulses** and transmitted through
fiber-optic cables.

### Advantages

-   🚀 High-speed communication
-   📏 Suitable for long distances
-   🔒 Less affected by electromagnetic interference

### Signal

> 💡 Pulses of light

------------------------------------------------------------------------

## 📶 3. Wireless Signals

Data is transmitted through the air using electromagnetic waves.

Examples include:

-   📻 Radio waves
-   📡 Microwaves
-   🔴 Infrared

### Signal

> 📶 Radio/electromagnetic waves

------------------------------------------------------------------------

# 📊 Signal Transmission Comparison

  Method          Signal                        Common Medium
  --------------- ----------------------------- -------------------
  ⚡ Electrical   Electrical pulses             Copper cable
  💡 Optical      Light pulses                  Fiber-optic cable
  📶 Wireless     Radio/electromagnetic waves   Air

### 🧠 Quick Memory Trick

**Copper → Electricity ⚡**\
**Fiber → Light 💡**\
**Wireless → Radio Waves 📶**

# 3️⃣ Bandwidth and Throughput

## 🚀 3.1 Bandwidth

**Bandwidth** is the **capacity of a medium to carry data**.

In networking, digital bandwidth describes how much data can
theoretically flow across a connection in a given amount of time.

Bandwidth is commonly measured in **bits per second (bps)**.

### Common Measurements

-   **Kbps** → Thousands of bits per second
-   **Mbps** → Millions of bits per second
-   **Gbps** → Billions of bits per second

### 📌 Examples

``` text
1 Kbps = thousands of bits/second
1 Mbps = millions of bits/second
1 Gbps = billions of bits/second
```

------------------------------------------------------------------------

# 📈 3.2 Throughput

**Throughput** is the amount of data that is **actually transferred**
across a connection over a given period of time.

In real networks:

> **Throughput is usually lower than the specified bandwidth.**

### Why?

Several factors can affect throughput:

-   📊 Amount of data being transmitted
-   📦 Type of data being transmitted
-   ⏱️ Network latency
-   🌐 Number of network devices between source and destination
-   🐌 Slow links along the path
-   ⚙️ Network conditions

------------------------------------------------------------------------

# ⏱️ 3.3 Latency

**Latency** is the amount of time, including delays, required for data
to travel from one point to another.

### Simple Definition

> **Latency = Delay in data transmission**

### Example

If you click a button and the server takes time to respond, the delay
you experience is related to **latency**.

### High Latency

🐌 Slow response

### Low Latency

⚡ Fast response

------------------------------------------------------------------------

# 🔗 3.4 The Slowest Link Principle

In a network with multiple segments:

> **Throughput cannot be faster than the slowest link along the path.**

### Example

Suppose a data path contains:

``` text
Device A
   ↓
100 Mbps
   ↓
Router
   ↓
10 Mbps
   ↓
Router
   ↓
100 Mbps
   ↓
Device B
```

Even though most links support **100 Mbps**, the **10 Mbps link** can
become the bottleneck.

### ⭐ Remember

> **One slow link can reduce the effective throughput of the entire
> path.**

------------------------------------------------------------------------

# ⚖️ 3.5 Bandwidth vs Throughput

  Feature                Bandwidth                      Throughput
  ---------------------- ------------------------------ ----------------------
  Meaning                Maximum/theoretical capacity   Actual data transfer
  Represents             Capacity                       Real performance
  Affected by latency?   Not directly                   Yes
  Typical value          Specified by connection        Measured during use
  Example                100 Mbps connection            Actual 85 Mbps

### 🧠 Easy Analogy

Imagine a highway:

-   🛣️ **Bandwidth** = Number of lanes available
-   🚗 **Throughput** = Number of cars actually moving
-   🚦 **Latency** = Time taken to travel between points
-   🚧 **Slow link** = A narrow section causing a bottleneck

------------------------------------------------------------------------

# 📥 3.6 Download vs Upload

Network performance can be measured in both directions.

### 📥 Download

Data is transferred **from the Internet/server to your device**.

Examples:

-   Watching a video
-   Downloading a file
-   Receiving a webpage

### 📤 Upload

Data is transferred **from your device to the Internet/server**.

Examples:

-   Uploading a picture
-   Sending a video
-   Uploading a file

In many home Internet connections, the **download rate may be higher
than the upload rate**.

------------------------------------------------------------------------

# 📊 3.7 Measuring Network Performance

Internet speed-test tools can be used to measure network performance.

They commonly report:

-   📥 Download speed
-   📤 Upload speed
-   📡 Connection performance

The result is generally expressed in **bits per second**, such as Mbps.

### Example

``` text
Download: 35.70 Mbps
Upload:   35.04 Mbps
```

> These measurements help estimate how much data can actually be
> transferred through an Internet connection.
