# 📶 3.1 Wireless Networks

## 🎯 Learning Objective
Describe the different types of networks used by **cell phones and mobile devices**.

## 📱 Cellular Networks
- Mobile phones use **radio waves** to transmit voice signals to antennas mounted on towers.
- Cellular towers cover specific **geographic areas**.
- During communication, signals can be relayed from **one tower to another** until reaching the destination.
- Cellular networks support **voice calls, text messages, and mobile data**.
- The course identifies **GSM** as a common cellular telephone network.
- Generations mentioned in the course include **3G, 4G, 4G-LTE, and 5G**.
- These generations are associated with enhanced networks optimized for faster data transmission.

> 🧠 **Remember:** Cellular network = mobile communication through radio signals and cellular towers.

## 📶 Wi-Fi
- Smartphones contain **Wi-Fi transmitters and receivers**.
- Wi-Fi connects mobile devices to **local networks and the Internet**.
- A **hotspot** is an area where Wi-Fi signals are available.
- Wi-Fi networks may be privately owned or provide guest/public access.

> 🧠 **Remember:** Wi-Fi = local wireless network access, commonly used for Internet connectivity.

## 🔵 Bluetooth
- Bluetooth is a **short-range wireless technology**.
- It allows devices to communicate without cables.
- It uses relatively **little power**, helping conserve battery life.
- Common uses include headsets, keyboards, mice, speakers, car speakerphones, and stereo controls.

> 🧠 **Remember:** Bluetooth = short range + low power + accessories.

## 💳 NFC — Near Field Communication
- NFC enables data exchange when devices are in **very close proximity**.
- The course describes the range as usually **less than a few centimeters**.
- A common example is communication between a smartphone and a **payment system**.

> 🧠 **Remember:** NFC = very short range + close proximity.

## 🛰️ GPS
- GPS is used for **location-related services**.
- Its primary purpose is determining location rather than providing a local data connection.

## 📊 Wireless Technologies — Quick Comparison

| Technology | Main Purpose | Key Characteristic |
|---|---|---|
| Cellular | Voice, SMS, mobile Internet | Uses cellular towers |
| Wi-Fi | Local network / Internet | Local wireless networking |
| Bluetooth | Accessories / nearby devices | Short range, low power |
| NFC | Close-proximity data exchange | Usually a few centimeters |
| GPS | Location services | Determines position |

## 📝 3.1 Check Your Understanding
- **Q1:** Low-power, shorter-range technology for accessories such as speakers or a mouse → **Bluetooth**.
- **Q2:** Smartphone communication with a payment system within a few centimeters → **NFC**.

# 📱 3.2 Mobile Device Connectivity

## 🎯 Learning Objective
Configure mobile devices for **wireless connectivity**.

## 📱 Mobile Devices and Wi-Fi
- Mobile devices allow users to **work, learn, play, and communicate** without being tied to physical network cables.
- Wireless networks are common in homes, offices, college campuses, and Internet cafes.
- Almost all mobile devices can connect to **Wi-Fi**.
- Wi-Fi data generally does **not count against a cellular data plan**.
- Wi-Fi radios use less power than cellular radios, which can help **conserve battery life**.

## 🔐 Wi-Fi Security
When using Wi-Fi on mobile devices:
- Never send login or password information using **unencrypted plaintext**.
- Use a **VPN** when possible when transmitting sensitive data.
- Enable security on home networks.
- Use **WPA2 or higher encryption** for security.

> ⚠️ **Security Tip:** Avoid sending sensitive information over an unsecured wireless connection.

## ⚙️ Wi-Fi Settings
- Two popular mobile operating systems discussed are **Android** and **Apple iOS**.
- To connect to an available Wi-Fi network:
  1. Turn **Wi-Fi ON**.
  2. Search for available networks.
  3. Select the desired network.
  4. Enter the password if required.
  5. Connect.
- A device can automatically reconnect to a Wi-Fi network it has used previously.
- If Wi-Fi is unavailable, the device can use **cellular data** when configured.

## 🛠️ Configure Mobile Wi-Fi Connectivity
- **SSID:** The name assigned to a wireless network.
- **Passphrase:** The wireless network password.
- SSID and passphrase values must be entered **exactly** as configured.

### 🤖 Android — Manual Wi-Fi
1. **Settings > Add network**
2. Enter the **network SSID**.
3. Select **Security** and choose a security type.
4. Enter the **Password**.
5. Select **Save**.

### 🍎 iOS — Manual Wi-Fi
1. **Settings > Wi-Fi > Other**
2. Enter the **network SSID**.
3. Select **Security** and choose a security type.
4. Select **Other Network**.
5. Enter the **Password**.
6. Select **Join**.

> 📌 Menu names can vary between operating-system versions and device manufacturers.

## 📡 Cellular Data Settings
- Cellular data plans vary in **bandwidth limitations and charges**.
- Many users prefer Wi-Fi when available.
- iOS path given in the course: **Settings > Cellular Data > turn cellular data on/off**.

## 🔄 Wi-Fi-to-Cellular Transition
- Mobile devices are generally configured to use **Wi-Fi** for Internet access when available.
- If no Wi-Fi is available, the device uses **cellular data** if configured.
- A mobile device can transition between cellular coverage types, such as **4G and 3G**, without an obvious loss of connection.

# 🔵 Bluetooth Connectivity

## ⭐ Key Characteristics
- Wireless
- Simple to configure
- Low power consumption
- Useful for short-range connections
- The course states that **up to eight Bluetooth devices** can be connected together at one time.

## 🎧 Common Bluetooth Uses
- **Hands-free headset** — making and receiving calls.
- **Keyboard or mouse** — easier input.
- **Stereo control** — playing music through a home or car stereo.
- **Car speakerphone** — hands-free calling.
- **Tethering** — sharing a network connection with another device or computer.
- **Mobile speaker** — wireless audio.

## 🔗 Bluetooth Pairing
**Bluetooth pairing** occurs when two Bluetooth devices establish a connection to share resources.

### Basic Pairing Process
1. Turn on the Bluetooth radios.
2. Put the required device into **discoverable/visible mode**.
3. Search for available Bluetooth devices.
4. Select the discovered device.
5. Enter a **PIN/passkey** if requested.
6. Complete the connection.

## 📋 Discoverable Bluetooth Information
A discoverable device can provide:
- **Name**
- **Bluetooth class**
- **Available services**
- **Technical information**, including supported Bluetooth specifications/features

## 🔑 Bluetooth PIN
- A PIN may authenticate the pairing process.
- It can be a number, numeric code, or passkey.
- Pairing services can store the PIN to simplify future connections.

### 🤖 Android — Bluetooth Pairing
1. Place the device in discoverable mode.
2. Find the connection PIN from the device instructions.
3. **Settings > Wireless and networks**
4. Turn **Bluetooth** on.
5. Open the **Bluetooth tab**.
6. Select **Scan for devices**.
7. Select the discovered device.
8. Enter the **PIN**.
9. Select the device name again to connect.

### 🍎 iOS — Bluetooth Pairing
1. Place the device in discoverable mode.
2. Find the connection PIN if required.
3. **Settings > Bluetooth**
4. Turn **Bluetooth ON**.
5. Select the discovered device.
6. Enter the **PIN**.

> 📌 Mobile operating systems are updated frequently. Use the manufacturer's documentation for the exact steps for a particular device.

## 🧩 Multiple Wireless Services Together
A mobile device can use multiple wireless services at the same time:
- **Bluetooth** → listen to music through headphones.
- **Wi-Fi** → research on the Internet.
- **Cellular** → receive text messages.
